## Fixes Completed

### 1. Aggregate SHA drift is now non-blocking

- Changed [src/pkg/installer/installer.go](/Users/randlee/Documents/github/synaptic-canvas-dolt-worktrees/feature/p5-s5-package-expansion/src/pkg/installer/installer.go:165) so package aggregate mismatch:

  - does not return an install error
  - is emitted as an install warning
  - is recorded in the install lockfile for later validation/readback
- Added validation surfacing in [src/pkg/operations/validation.go](/Users/randlee/Documents/github/synaptic-canvas-dolt-worktrees/feature/p5-s5-package-expansion/src/pkg/operations/validation.go:40) so the recorded mismatch appears as a warning-level aggregate finding instead of disappearing.

### 2. Structured `requires:` manifests now import

- Extended importer manifest parsing in [src/pkg/importer/importer.go](/Users/randlee/Documents/github/synaptic-canvas-dolt-worktrees/feature/p5-s5-package-expansion/src/pkg/importer/importer.go:87) so `requires:` accepts:
  - legacy `[]string`
  - grouped mappings like:
    - `cli: [...]`
    - `optional: [...]`
    - other nested/scalar map forms
- Unknown manifest fields such as `shared_scripts:` remain non-fatal.
