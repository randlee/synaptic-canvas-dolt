## Implementation Notes

Fixture verification for `sc:plugin` can use golden-file tests or
table-driven tests in `.claude/skills/sc-plugin/tests/`. Each test case
specifies: input utterance, expected `sc` invocation flags, and expected
JSON output shape. The test runner invokes the actual `sc` binary and
compares structured output.

The `//go:build` tag for `dolttest/harness.go` should be
`//go:build testonly` or equivalent — whichever convention the repo uses for
test-support packages that must not enter production builds.
