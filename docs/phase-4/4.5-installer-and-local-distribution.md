# Sprint 4.5 — Installer And Local Distribution

## Goal

- Install or upgrade the `sc` binary and `sc:plugin` skill on supported
  platforms with predictable config behavior.

## Hard Dependencies

- Sprint `4.4` complete.

## Normative References

- Requirement: `REQ-005`
- Requirement: `CLI-003`
- Requirement: `FS-001`
- Requirement: `FS-002`
- Requirement: `VER-003`
- ADR: `ADR-0003`

## Exact Targets

- `scripts/install.sh`
- `scripts/install.ps1`
- `.github/workflows/*`
- `docs/synaptic-canvas-cli.md`

## Required Work

- Add installer scripts for macOS/Linux and Windows.
- Ensure fresh install places the `sc` binary on PATH and installs
  `sc:plugin` globally.
- Define the managed install roots explicitly:
  the `sc` binary in the selected executable location,
  `sc:plugin` under `~/.claude/skills/sc-plugin/`,
  and CLI config under `~/.sc/config.toml`.
- Preserve user-owned config on rerun or upgrade while updating managed
  binaries and skill assets.
- Define how installer reruns detect and replace only product-managed files
  while leaving user-edited config intact.
- Add repository-owned verification for installer behavior on supported
  platforms.

## Implementation Notes

The installer should maintain a clear managed/unmanaged split:
- managed: installed binary, managed skill files, generated defaults
- unmanaged: user-edited config values, unrelated user files, repository-local
  installs

Required scenarios:
- fresh install on macOS/Linux
- fresh install on Windows
- rerun with existing binary and existing global skill
- upgrade preserving `~/.sc/config.toml`
- rerun when `sc:plugin` exists with expected managed files
- rerun when user has added unrelated files under `~/.claude/`

## Acceptance Criteria

- Fresh install makes `sc --version` work and installs `sc:plugin` globally.
- Upgrade reruns preserve config values while updating managed binaries and
  skill assets.
- Installer behavior is predictable and sufficiently idempotent for support
  and development workflows.
- Repository-owned verification exists for installer behavior on supported
  platforms.
- The installer never deletes or overwrites user-owned config values outside
  explicitly managed files.
